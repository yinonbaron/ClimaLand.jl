# Validate all sites and activate each pathway

Baseline and regression validation covers all 59 sites in the released CLASSIC benchmarking collection, with at least one complete seasonal trajectory per site. A pathway supports a parity claim only when validation evidence actually activates it, because broad site coverage cannot demonstrate behavior that every published configuration leaves dormant.

## Consequences

Published configurations are used unchanged wherever they activate the capability under review, and C-scope validation includes both published peat sites. When no published case activates a D-scope pathway, a minimal derived configuration may be used only if its exact changes from the published baseline are recorded; pathway evidence supplements rather than replaces all-site validation.
